<chart_generation_examples>
EXAMPLE 1: Bar Chart for Market Share

```python
import matplotlib.pyplot as plt
import os
os.makedirs('files/charts', exist_ok=True)
companies = ['Company A', 'Company B', 'Company C']
shares = [40.0, 30.0, 30.0]
plt.figure(figsize=(10, 6))
plt.bar(companies, shares)
plt.title('Market Share 2024', fontsize=14, fontweight='bold')
plt.ylabel('Market Share (%)')
for i, v in enumerate(shares):
    plt.text(i, v + 0.5, f'{v}%', ha='center')
plt.tight_layout()
plt.savefig('files/charts/market_share.png', dpi=150, bbox_inches='tight')
plt.close()
print("Saved: files/charts/market_share.png")
```

EXAMPLE 2: Line Chart for Growth Trends

```python
import matplotlib.pyplot as plt
import os
os.makedirs('files/charts', exist_ok=True)
years = [2020, 2021, 2022, 2023, 2024]
values = [10, 15, 22, 30, 42]
plt.figure(figsize=(10, 6))
plt.plot(years, values, marker='o', linewidth=2)
plt.fill_between(years, values, alpha=0.3)
plt.title('Growth Trend (2020-2024)', fontsize=14, fontweight='bold')
plt.ylabel('Value')
plt.xlabel('Year')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('files/charts/growth_trend.png', dpi=150, bbox_inches='tight')
plt.close()
print("Saved: files/charts/growth_trend.png")
```
